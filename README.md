# РосКапСтрой — PWA строительного контроля

Бесплатная веб-версия приложения строительного контроля, ориентированная на iPhone 16 Pro / iOS 26. Устанавливается через Safari на экран «Домой» и не требует публикации в App Store.

## Что реализовано

- чёрный загрузочный экран с фирменным логотипом РосКапСтрой;
- главный журнал замечаний, компактный поиск, фильтры и статусы;
- автоматическая нумерация `РКС-000001`, при этом номер можно отредактировать вручную;
- единое отображение номера в журнале, карточке и PDF;
- карточка замечания: объект, точное место, раздел работ, тип недостатка, подрядчик, статус;
- раздел работ содержит аббревиатуру и расшифровку + свой вариант;
- тип недостатка + свой вариант;
- фото недостатка и фото после устранения с камеры iPhone или медиатеки;
- автоматическое уменьшение фотографий до 1600 px по длинной стороне и JPEG ~72%;
- описание недостатка и указания по устранению;
- список НТД из согласованного перечня; для каждого выбранного документа пункт вводится вручную и обязателен;
- плановая дата устранения и дата подписания документа;
- поле «Кем выдан» по умолчанию: `Ведущий инженер ОСК Щипин С.А.`;
- кнопка `PDF`: приложение само формирует PDF «Лист замечания» с русским текстом и фотографиями; PDF создаётся локально в браузере без стороннего сервера;
- на iPhone готовый PDF передаётся в системное меню «Поделиться», на ПК скачивается файлом;
- локальная IndexedDB: замечания и фотографии остаются на устройстве;
- экспорт/импорт полной резервной копии JSON;
- импорт справочника объектов из JSON/CSV/TXT;
- настройки: размер текста 80–140%, жирный текст, высокая контрастность, увеличенные кнопки, системная/светлая/тёмная тема;
- offline cache через Service Worker;
- Liquid Glass используется только для навигации и действий, а не для основного контента.

## Структура

- `index.html` — интерфейс;
- `styles.css` — фирменная UI-система;
- `app.js` — логика, IndexedDB, фото, справочники, PDF;
- `manifest.webmanifest` — установка PWA;
- `sw.js` — offline cache;
- `assets/` — логотип и master app icon;
- `icons/` — PWA / Apple touch icons.

## Как проверить на ПК

PWA нужно открывать по HTTP, а не двойным кликом по `index.html`.

Если установлен Python:

```bash
cd roskapstroy-pwa
python -m http.server 8080
```

После этого открыть:

```text
http://localhost:8080
```

## Бесплатное размещение

### GitHub Pages

1. Создайте публичный репозиторий GitHub.
2. Загрузите в него содержимое папки `roskapstroy-pwa`.
3. В GitHub откройте `Settings → Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/ (root)`.
6. GitHub выдаст HTTPS-адрес приложения.

### Cloudflare Pages

Также можно бесплатно подключить этот же GitHub-репозиторий к Cloudflare Pages. Сборка не требуется: проект полностью статический.

## Установка на iPhone

1. Открыть HTTPS-адрес приложения именно в Safari.
2. `Поделиться` → `На экран «Домой»`.
3. Подтвердить название «РосКапСтрой».
4. Запускать приложение с созданной иконки.

Такой вариант не требует Apple Developer Program и еженедельной переподписи.

## Данные и синхронизация

Сейчас данные хранятся локально на конкретном устройстве. Для бесплатной синхронизации iPhone ↔ Windows следующим этапом можно подключить Supabase Free, оставив IndexedDB как offline-кэш.

Важно: перед очисткой Safari/данных сайта рекомендуется сделать `Настройки → Экспорт резервной копии`.

## v11 — специализированные карточки видов контроля

Модуль «Фотофиксация» теперь меняет рабочую карточку в зависимости от выбранного вида контроля:

- **Операционный контроль** — этап/технологическая операция, контролируемый параметр, способ контроля/инструмент, предшествующие работы, признак скрываемой работы.
- **Приемочный контроль** — предъявленный объём, исполнительная документация, испытания/измерения к приёмке, готовность к следующему этапу, ранее выданные замечания.
- **Индивидуальные испытания** — оборудование, заводской номер, программа/методика, средство измерений, номер/поверка прибора, нормативные и фактические параметры.
- **Комплексное опробование** — комплекс/система, программа, продолжительность, итоговый протокол и динамический пошаговый сценарий «событие → команда → ожидаемый результат → фактический результат → итог этапа».

Специализированные данные сохраняются в IndexedDB, резервной копии и PDF-фотоотчёте. Поиск журнала учитывает новые поля. Формат резервной копии обновлён до schema 5 с обратным чтением версий 1–4. Service Worker cache: `rks-pwa-v11-specialized-control`.

## V1.9 — PDF save flow

- Основное действие после генерации: `Сохранить PDF`.
- На поддерживаемых iPhone/iPad PDF передаётся в системное меню только как `File` через `navigator.share({files:[file]})`; перед вызовом нет Service Worker, Cache API или асинхронных операций.
- Blob URL используется только для предварительного просмотра.
- `Скачать как файл` оставлен как резервный fallback.
- В окно PDF добавлена диагностика: генерация, размер, File API, Web Share, `canShare({files})`, user activation, standalone-PWA, Service Worker и последняя ошибка WebKit.
- Сообщение об успешном `navigator.share()` больше не утверждает, что файл сохранён: приложение может знать только, что системное меню было завершено.
- Service Worker больше не перехватывает и не хранит динамические PDF.
