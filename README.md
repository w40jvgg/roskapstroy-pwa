# РосКапСтрой V2.0

Мобильное PWA для инженеров строительного контроля. Рабочие записи, фотографии, PDF и резервные копии обрабатываются локально и не отправляются на сервер.

## Возможности

- три журнала: «Замечания», «Проверка», «Фотоотчёт»;
- автосохранение черновиков в IndexedDB (Dexie), внутренние UUID и независимые счётчики;
- фотографии с камеры/из галереи, document-копии и thumbnails;
- локальная генерация PDF с кириллицей и сетками 1/2/4/6 фото;
- ZIP-экспорт и транзакционное восстановление с SHA-256-проверкой;
- офлайн app shell, уведомление об обновлении и установка PWA;
- светлая/тёмная тема, масштаб текста, высокая контрастность и reduced motion;
- свайпы между модулями плюс доступные вкладки и клавиатура.

## Запуск

```bash
npm install
npm run dev
```

## Проверка и production-сборка

```bash
npm run test
npm run build
npm run preview
```

Готовая статическая сборка создаётся в `dist/`. Базовый путь production-сборки — `/roskapstroy-pwa/`.

## Ручная публикация на GitHub Pages

1. Загрузите исходный проект в репозиторий `roskapstroy-pwa`.
2. Выполните `npm ci` и `npm run build`.
3. Опубликуйте содержимое `dist` через GitHub Pages (ветка `gh-pages` или GitHub Actions).
4. Проверьте адрес `https://<владелец>.github.io/roskapstroy-pwa/` один раз онлайн, затем повторно откройте без сети.

`dist/.nojekyll` создаётся автоматически из `public/.nojekyll`. Секреты и переменные окружения для основной работы не нужны.

## Данные и совместимость

Схема IndexedDB версионирована. Старый статус `Открыто` отображается как `В работе` с сохранением legacy-значения. Старый store `photoRecords` не удаляется; его записи идемпотентно переносятся в журнал фотоотчётов с сохранением исходных полей в `legacy`.

Перед крупным обновлением рекомендуется выполнить «Настройки → Данные → Экспорт всех данных».
