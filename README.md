# РосКапСтрой · Контроль

Приложение для ежедневной работы строительного контроля с тремя модулями: «Замечания», «Фотоотчёт» и «Проверка ИД».

Умный поиск объектов работает по номеру ГП, шифру и словам названия. Справочник объектов перенесён из предоставленной книги Excel; поиск РД работает по отдельному справочнику рабочей документации.

В замечании ответственная организация выбирается из вариантов исходного приложения: «ЭнергоСК», «ИСЭ», «ТЭК Мосэнерго» и «Откл».

В замечаниях и фотоотчётах можно выбрать раскладку для PDF: 1, 2, 4 или 6 фотографий на листе. Настройка сохраняется вместе с записью.

Новому замечанию предлагается следующий свободный номер. Его можно изменить вручную или выключить переключателем «Указывать номер замечания». При выключении номер не появляется в карточке и PDF.

## Публикация

Загрузите содержимое этой папки в корень репозитория GitHub. В настройках Pages включите публикацию из ветки `main`, папка `/ (root)`. После публикации откройте выданный HTTPS-адрес. HTTPS нужен для установки приложения на устройство и работы офлайн-кэша.

На iPhone откройте опубликованный адрес в Safari и выберите «Поделиться» → «На экран Домой». После первого открытия дождитесь загрузки ресурсов; затем приложение может открываться без сети. На компьютере откройте тот же адрес в браузере. Библиотеки для Word и PDF подгружаются только при первом создании соответствующего файла, чтобы журнал открывался быстрее.

## Хранение и резервирование

Записи, фото и прикреплённые документы сохраняются в локальном хранилище браузера на текущем устройстве. Между устройствами они автоматически не синхронизируются. Кнопка «Резервная копия» выгружает записи и вложения в JSON; «Импорт» восстанавливает копию. Храните резервный файл отдельно.

## Проверка ИД

В карточке проверки отображается настраиваемый список документов: общий журнал, реестр, АТГ, ведомости, исполнительные схемы, техническое решение, журналы, протоколы и акт передачи в ПНР. Список можно переименовывать, добавлять, удалять и переставлять.

Откройте строку документа, чтобы вручную добавить или отредактировать замечания. Кнопка «Сохранить» сохраняет замечание и возвращает к списку документов. В итоговом Word и PDF остаются только включённые документы и замечания; нумерация сквозная. Для актов и ведомостей номер документа обязателен.

Документ проверки можно выгрузить в Word (.docx) или PDF. Выгрузки оформляются шрифтом Arial 12 pt, включают логотип, заключительный текст, должность, ФИО и дату.
