# РосКапСтрой V1.8 — PWA

Статическое PWA-приложение для строительного контроля. Backend не требуется.

## Запуск локально

Из каталога проекта:

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`.

> Service Worker и установка PWA работают через HTTP на localhost или через HTTPS.

## Размещение на GitHub Pages

Загрузите содержимое каталога в корень репозитория и включите GitHub Pages для ветки `main`, каталог `/ (root)`.

## Реализовано

- три модуля: Замечания / Проверка / Фотоотчёт;
- горизонтальный pager со свайпом, velocity threshold и rubber-band на границах;
- IndexedDB: `defects`, `photoRecords`, `photoReports`, `drafts`, `metadata`;
- автосохранение черновиков;
- камера и галерея как отдельные действия;
- оптимизация фото до максимальной стороны ~1600 px;
- поиск по текущему модулю;
- статусы и просрочка;
- специализированные формы четырёх видов проверки;
- сценарии комплексного опробования;
- локальная генерация PDF A4;
- сетки 1 / 2 / 4 / 6 фото, contain без обрезки;
- импорт/экспорт полной резервной копии JSON;
- системная / светлая / тёмная тема;
- настройка размера текста, контрастности и размеров кнопок;
- справочник объектов;
- PWA manifest + service worker + offline cache.

## Примечание по PDF

Чтобы приложение не зависело от внешних шрифтов и работало полностью офлайн, страницы PDF растрируются локально в браузере в A4-холсты и помещаются в PDF как изображения. Это гарантирует корректное отображение кириллицы и фотографий на iOS/Android/desktop без загрузки рабочих данных на сервер.
