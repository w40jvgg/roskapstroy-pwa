РОСКАПСТРОЙ PWA V2.0 — ЗАПУСК НА WINDOWS

1. Распакуйте архив полностью в обычную папку.
2. Дважды нажмите START_APP.bat.
3. Браузер автоматически откроет http://localhost:4173/
4. Не закрывайте окно запуска, пока работаете с приложением.
5. Для остановки нажмите Ctrl+C в окне запуска.

ВАЖНО:
Не запускайте dist/index.html двойным кликом. PWA использует JavaScript-модули,
IndexedDB и Service Worker, для которых нужен http://localhost или HTTPS.

Для публикации на GitHub Pages / любом статическом хостинге используйте содержимое папки dist.
Сборка исправлена и больше не привязана к пути /roskapstroy-pwa/.
