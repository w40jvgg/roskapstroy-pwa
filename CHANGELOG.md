# История изменений РосКапСтрой

## 21.09.2026 — V1.9.17 — Единый интерфейс рабочих карточек

- Дизайн «Простой и удобный» применён к созданию и редактированию карточек «Проверка» и «Фотоотчёт».
- Основные действия выстроены вертикально для работы одной рукой на iPhone 16 Pro.
- Специализированные поля видов контроля и дополнительные сведения сохранены без изменения структуры данных.
- Фото добавляются через единый источник «Камера / Галерея», фотоблоки уплотнены без изменения хранения и PDF.
- Добавлена корректировка прокрутки активного поля при появлении мобильной клавиатуры.
- Схема IndexedDB, импорт/экспорт, PDF, поиск РД и существующие записи не изменялись.
